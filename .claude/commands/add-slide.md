## Instructions

1. Read `workplan.md` and find the last numbered slide in the "Slide Outline" section
2. Ask the user for: slide title, key content points, and any image notes
3. Add a new slide entry using the existing format:
   - Slide number (next in sequence)
   - **Title** in bold
   - Content as bullet points, tables, or notes
   - Image placeholder comment
4. Add a row to the Images table with the new slide number
5. Show the user the new entry before writing it
