## Instructions

1. Read `workplan.md` in the current folder
2. Check each slide in the outline for:
   - **Missing content**: slides with no bullet points or tables
   - **Missing images**: image placeholders that reference files not found in `images/`
   - **Unused images**: files in `images/` not referenced by any slide
   - **Empty sections**: Design Guidelines, Source Materials, or other sections with only placeholder comments
3. Check the status checklist and report which items are still unchecked
4. Report a summary: total slides, ready vs incomplete, image coverage, next action needed
